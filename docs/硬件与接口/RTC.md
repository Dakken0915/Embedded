# RTC 实时时钟

RTC 使用低速时钟源跟踪时间，并可产生闹钟、周期唤醒或时间戳事件。带备份域和备用电源的器件可在主电源关闭期间继续计时；是否保时取决于具体芯片的备份供电设计。

## RTC 与通用定时器

| 项目 | RTC | 通用定时器 |
| --- | --- | --- |
| 典型时钟 | LSE、LSI 或专用低功耗源 | APB/内核等高速时钟 |
| 断电保持 | 备份域供电满足时可保持 | 主电源断开通常停止 |
| 典型功能 | 日历、闹钟、唤醒、时间戳 | PWM、输入捕获、编码器、周期中断 |
| 误差来源 | 振荡器精度、温漂、校准 | 输入时钟误差与分频设置 |

## 初始化流程

常见流程为开启电源管理与备份域访问、检查备份标记、启动并等待低速振荡器稳定、选择 RTC 时钟、同步寄存器、配置分频与日历、设置初始时间并写入校验标记。若备份域状态和时钟配置有效，重新上电时不应无条件复位当前时间。

某些 MCU 的 RTC 按日历寄存器工作，另一些以递增计数器表达时间；寄存器同步、格式转换、闰年与夏令时策略均依芯片和应用定义。备份寄存器容量有限，不适合直接存放任意大小的配置。

## 唤醒与时间一致性

低功耗唤醒事件通常需要 RTC 内部事件与外部中断控制器共同配置。中断服务程序应确认并清除来源，再通知任务。读取日历时应避免跨秒读出不一致字段，可使用芯片提供的快照/同步机制或重复读取校验。

看门狗时基、RTC 时基与主系统时钟可能彼此独立，计算超时和恢复时不得混用频率假设。
