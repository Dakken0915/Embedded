# SPI 总线

SPI 通常使用 SCK、MOSI、MISO 和一个或多个片选信号。它没有统一的设备寻址、帧格式或总线仲裁标准，具体命令和片选时序由外设定义。

## 时钟模式与数据方向

CPOL 决定 SCK 空闲电平，CPHA 决定数据相对采样边沿的相位。外设数据手册中的模式须与控制器一致。

| 模式 | CPOL | CPHA | 空闲电平 | 采样边沿 |
| --- | ---: | ---: | --- | --- |
| 0 | 0 | 0 | 低 | 第一个边沿，上升沿 |
| 1 | 0 | 1 | 低 | 第二个边沿，下降沿 |
| 2 | 1 | 0 | 高 | 第一个边沿，下降沿 |
| 3 | 1 | 1 | 高 | 第二个边沿，上升沿 |

典型四线 SPI 移位寄存器在每个时钟周期同时移出与移入一位，因此发送与接收是全双工的。但协议可以在命令阶段忽略接收数据，在后续时钟阶段继续发送 dummy 字节以产生读时钟；这并不违背全双工硬件行为。

## 初始化与片选

初始化包括使能控制器和 GPIO 时钟、配置复用、主从模式、CPOL/CPHA、时钟分频、位宽、位序及片选方式，然后使能 SPI。主机通常控制片选；多个从设备可共享时钟和数据线，但各自需独立片选。MISO 未选中时的三态行为及总线冲突须由器件保证。

硬件 NSS 与软件 GPIO 片选的时序行为并不相同。一次事务可由多个阶段组成，某些设备要求命令和数据之间片选持续有效，不能在每字节之间无条件翻转片选。

## DMA 与完成状态

DMA 半传输/完成中断代表缓冲区搬运进度；SPI 总线最终位完成还需检查控制器状态。非缓存一致系统需按平台规则处理缓冲区 Cache 与所有权。错误处理需清除溢出、模式错误等状态，事务结束后关闭 DMA 请求并释放片选。

SPI 常用于短距离板内高速外设，I2C 以两线寻址支持多器件但受总线电容和上拉约束。吞吐、引脚数量、器件供给、距离与 EMC 共同决定选型，不能仅按理论最高时钟比较。
