# ADC 模数转换

ADC 将模拟输入映射为有限位数的数字码。量化步长近似取决于参考电压与分辨率，测量精度还受参考源、输入驱动能力、采样保持时间、偏置、噪声和校准影响。

## 初始化与采样

典型初始化包括使能 GPIO 与 ADC 时钟、将通道引脚设为模拟模式、配置 ADC 时钟与分辨率、通道采样周期、触发源、序列长度及对齐方式，然后使能并按芯片要求校准。ADC 时钟必须在额定范围内；高源阻抗信号通常需要更长采样时间或缓冲放大器。

单次轮询适合低速简单采样；定时器触发与 DMA 适用于稳定周期和连续采样。DMA 半传输和完成事件可处理分块数据，缓冲区复用时必须避免 CPU 与 DMA 同时写读同一区域。

## 码值换算与误差

理想单端 ADC 对 N 位结果的电压可近似换算为 `V = code × Vref / (2^N - 1)`；部分 ADC 的码值边界、双极性编码和校准模型不同，应以芯片手册为准。过采样可降低部分随机噪声，但不能消除系统偏差或不稳定参考电压。

采样输入前应检查绝对最大额定值、输入钳位电流和电压范围。分压、RC 滤波与保护网络会影响响应时间和采样建立时间。
