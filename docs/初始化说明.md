# 知识库初始化与目录结构

## 系统目录

当前仓库为 Docusaurus 嵌入式技术知识库。目录以工作区实际结构为准。

```text
Embedded/
├── AGENTS.md                     # 项目初始化约定、目录职责和维护规则
├── README.md                     # 安装与运行说明
├── record.md                     # 目录与内容变更记录
├── docs/                         # Docusaurus 唯一正式文档目录
│   ├── 语言与构建/                # C语言/、C++语言/，以及 Makefile、Shell
│   ├── Linux应用/                # 进程、错误码、线程、内存、调试、V4L2 与 libusb
│   ├── Linux驱动/                # 子目录与前端侧栏六组分类一致
│   │   ├── 基础理论/            # 设备模型、字符设备、内存映射、同步、中断
│   │   ├── 平台基础/            # 设备树与 Platform
│   │   ├── 底层引脚与时钟/      # CLK、GPIO、Pinctrl
│   │   ├── 总线与外设子系统/    # I2C、Input、USB
│   │   ├── 多媒体驱动/          # LCD/Framebuffer、V4L2
│   │   └── 调试工具/            # 内核日志
│   ├── 应用框架/                 # 软件分层、Qt 与 ROS 2
│   ├── 实时操作系统/              # FreeRTOS.md、uC-OS-III/ 源码机制专题
│   ├── 硬件与接口/                # UART.md、I2C.md、SPI.md、CAN.md、FPGA.md 等
│   ├── 算法与数据结构/            # 含算法题解及 C++ 源码
│   ├── 图像处理/                  # OpenCV/openCV.md：图像、视频与运动分析
│   ├── ESP32/
│   ├── 网络与通信/
│   ├── 系统与可靠性/
│   ├── 控制算法/
│   ├── 初始化说明.md
│   └── 知识索引.md
├── src/
│   ├── pages/                    # 根地址跳转知识索引
│   └── css/                      # 网站样式
├── examples/
│   ├── CAN/                      # 收发、帧格式、过滤器示例及参考资料
│   └── FPGA/                     # Verilog 示例及器件参考资料
├── static/img/knowledge/          # 正式知识页图片
├── scripts/                      # WSL IPv4 启动脚本和维护脚本
├── tmp/                          # 原始资料，不作为网站文档源或链接目标
├── docusaurus.config.js          # 网站配置
├── sidebars.js                   # 分类与侧栏
├── package.json                  # 构建命令和依赖
├── package-lock.json             # 依赖锁文件
├── build/                        # 生成的静态网站
├── .docusaurus/                  # 网站构建缓存
└── node_modules/                 # 安装的依赖
```

网站根路径 `/` 自动跳转到 `/docs/知识索引`，不提供独立展示首页。文档路由默认由文档路径确定；驱动页面归入六组子目录后，路由相应包含分组名称，例如 `/docs/Linux驱动/基础理论/字符设备与IO模型`。

## 目录维护

新增、删除或移动目录时，同步修订本页、`AGENTS.md`、README 中受影响的说明和 `record.md`。页面移动后同步维护首页、知识索引、`sidebars.js` 及正文中的链接。每个目录和页面的侧栏顺序都由 `sidebars.js` 显式维护，不使用自动生成或字典序。知识正文变更记录其实际涉及的专题，不为没有变化的目录制造更新。

`docs/` 的专题子目录与前端侧栏分类保持一致，不能只在侧栏创建分组而将对应正文留在父目录。用户明确指定的分组即使只有一篇页面，也保留实际目录；文档 ID 使用完整的新相对路径。

Linux 应用与 Linux 驱动分别使用根目录下的独立分类；Qt、ROS 2 和软件分层位于应用框架。用户态同步与内核锁、V4L2 用户态采集与驱动缓冲队列分别归档并互链。

正式知识按领域分类，同一专题避免重复嵌套。例如 CAN 位于 `docs/硬件与接口/CAN.md`，UART、I2C、SPI 等外设接口各自独立成页；配图位于 `static/img/knowledge/can/`，示例工程位于 `examples/CAN/`。FreeRTOS 与 uC/OS-III 分开归档；uC/OS-III 按移植、TCB、栈帧、就绪结构、调度及任务生命周期分为独立文章。C 与 C++ 分别设置子目录，混合笔记须按实际知识点拆分，不因原文件名称而遗漏其中其他领域的内容。

收集资料中的知识须经过归类、去重和书面化整理后写入正式文档。正式页面不能依赖其他文档目录才能阅读。非技术路线、方法说明和空白占位页不纳入正式知识导航。

接口调用、数据结构和算法按需配套代码，直接置于相应知识点旁。示例须说明版本、平台及调用前提，保留必要的边界检查、错误处理和资源释放；整理文章时保留有技术价值的代码。
