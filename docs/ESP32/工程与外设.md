# ESP32 工程与外设

本文以原始资料使用的 ESP-IDF 5.2 与 ESP32 为范围。其他芯片的引脚、外设资源及不同 SDK 主版本的 API 需要分别核对。

## 工程结构与组件

项目顶层 `CMakeLists.txt` 引入 ESP-IDF 构建系统并声明项目；`main/` 为主组件，`components/` 存放独立组件。组件通过 `idf_component_register()` 声明源文件、头文件搜索路径和依赖。`sdkconfig` 保存配置，分区 CSV 描述 Flash 布局，`build/` 保存构建产物。

```shell
idf.py set-target esp32
idf.py menuconfig
idf.py build
idf.py -p PORT flash monitor
```

`app_main()` 在系统完成基本初始化后的任务上下文中执行。ESP-IDF 的 FreeRTOS 移植具有特定的多核支持；`xTaskCreatePinnedToCore()` 可设置任务亲和性。ESP-IDF 任务创建接口中的栈深度单位为字节，不能照搬原生 FreeRTOS 常见的栈元素数量。SMP 临界区需要跨核同步，仅关闭本核中断不能阻止另一核心访问共享数据。见 [ESP-IDF 5.2 FreeRTOS](https://docs.espressif.com/projects/esp-idf/en/v5.2/esp32/api-reference/system/freertos_idf.html)。

## GPIO、LEDC 与按键

GPIO 配置包含方向、上下拉和中断类型；板上 LED 的有效电平取决于连接方式。LEDC 用定时器与输出通道生成 PWM，频率和占空比分辨率受时钟与计数范围共同约束。呼吸灯通过连续改变占空比实现亮度变化，不改变 GPIO 的高电平幅值。

按键处理区分原始电平、消抖后的稳定状态和逻辑事件。状态机记录按下时刻，达到阈值后产生长按事件，释放时按规则产生短按或结束事件。消抖与长按阈值使用时间基准，避免依赖不确定的循环次数；长按触发后是否允许短按需要明确。

### LEDC 定时器与通道配置

以下 ESP-IDF 5.2 示例使用低速模式、5 kHz 和 10 位分辨率，GPIO 18 仅为示例输出脚；实际使用前须确认板级连接及引脚占用。调用顺序为定时器配置、通道配置、占空比设置与更新，接口见 [LEDC 5.2](https://docs.espressif.com/projects/esp-idf/en/v5.2/esp32/api-reference/peripherals/ledc.html)。

```c
#include <stdint.h>
#include "driver/ledc.h"
#include "esp_err.h"

esp_err_t initializePwm(void)
{
    const ledc_timer_config_t timer = {
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .duty_resolution = LEDC_TIMER_10_BIT,
        .timer_num = LEDC_TIMER_0,
        .freq_hz = 5000,
        .clk_cfg = LEDC_AUTO_CLK
    };
    esp_err_t error = ledc_timer_config(&timer);
    if (error != ESP_OK) {
        return error;
    }

    const ledc_channel_config_t channel = {
        .gpio_num = 18,
        .speed_mode = LEDC_LOW_SPEED_MODE,
        .channel = LEDC_CHANNEL_0,
        .intr_type = LEDC_INTR_DISABLE,
        .timer_sel = LEDC_TIMER_0,
        .duty = 0,
        .hpoint = 0
    };
    return ledc_channel_config(&channel);
}

esp_err_t setPwmDuty(uint32_t duty)
{
    /* 此接口限定为 0～1023，避免传入超出示例约定的值。 */
    if (duty > 1023) {
        return ESP_ERR_INVALID_ARG;
    }
    esp_err_t error = ledc_set_duty(LEDC_LOW_SPEED_MODE,
                                   LEDC_CHANNEL_0, duty);
    if (error != ESP_OK) {
        return error;
    }
    return ledc_update_duty(LEDC_LOW_SPEED_MODE, LEDC_CHANNEL_0);
}
```

初始化成功后调用 `setPwmDuty(512)` 可得到约 50% 的占空比。该组设置与更新操作由一个任务串行执行；若多个任务共享同一通道，应增加同步或使用 SDK 提供的相应线程安全接口。

## RMT、WS2812 与 DHT11

RMT 用持续时间和电平组成的符号描述脉冲，可用于 WS2812 的单线时序输出，也可记录传感器输入脉冲。

WS2812 通常每颗灯接收 24 位颜色数据，颜色字节顺序、0/1 脉宽和复位低电平时间以具体器件版本为准。串联灯珠依次消费各自数据并转发剩余数据。发送缓冲区在硬件完成前必须保持有效，电源和逻辑电平需满足器件要求。

DHT11 的一次数据由 40 位、即 5 字节构成，不能写成 40 字节。主机发起起始信号后，传感器通过脉宽编码返回温湿度与校验字节。前四字节相加的低八位与第五字节比较；接收还需检查响应超时、数据长度和脉宽。温湿度范围、供电和最短采样周期取决于具体器件规格。

## ADC 与 NTC

NTC 热敏电阻随温度升高而阻值下降。先根据分压电路与采样电压计算电阻，再用器件参数换算温度。若上侧为已知电阻 Rs，下侧 NTC 接地，采样值为 V，则：

```text
Rntc = Rs·V/(Vcc-V)
1/T = 1/T0 + ln(Rntc/R0)/B
摄氏温度 = T - 273.15
```

温度公式中的 T、T0 使用开尔文。分压方向变化时必须调整公式，采样接近电源轨时还需处理除零与越界。

ESP-IDF 单次采样依次创建 ADC 单元、配置通道并读取；原始码值不是直接的电压，应按校准配置转换。经典 ESP32 的 ADC2 与 Wi-Fi 存在资源共享限制，不应泛化到所有 ESP 系列芯片。见 [ADC Oneshot 5.2](https://docs.espressif.com/projects/esp-idf/en/v5.2/esp32/api-reference/peripherals/adc_oneshot.html)。

## 超声波输入捕获

HC-SR04 由 Trig 触发，Echo 高电平时长表示声波往返时间，距离为 `d=v·Δt/2`。声速随环境变化，计时单位应一致。输入捕获保存上升沿和下降沿计数，使用计数频率换算时间，并考虑计数溢出、无回波超时和无效脉冲。

MCPWM 捕获外设可承担边沿计时；ISR 回调只记录计数并通知任务。某些模块 Echo 为 5 V，应按具体模块与 MCU 输入耐压决定是否进行电平转换。
