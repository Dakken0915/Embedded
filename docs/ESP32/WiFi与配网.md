# ESP32 Wi-Fi 与配网

## STA 连接流程

STA 模式中设备作为站点连接接入点。ESP-IDF 应用初始化 NVS、网络接口和事件循环，创建 STA 网络接口后初始化 Wi-Fi，注册事件处理器，设置模式和 SSID、认证信息，再启动连接。

关联到接入点和获得 IP 地址是不同阶段。应用通常在获得有效 IP 后启动依赖 IP 的通信服务。掉线时先使业务连接失效，再按有限重试、退避及恢复策略重连，避免在事件回调中阻塞。

## SmartConfig

SmartConfig 通过手机向局域网发送具有编码特征的数据，使未配置设备获得网络参数。具体方式对频段、路由器、手机网络权限和网络环境有要求，并不保证任何网络都能成功。

配网过程应区分启动、接收凭据、连接验证、应答和退出。只有验证成功的参数才进入持久化策略，超时、用户取消或重配时应清理任务和临时状态。配网、正常连接和故障恢复是不同状态，不能依靠一个永久等待循环混合处理。

## 连接安全与业务状态

Wi-Fi 凭据需要限制日志暴露与访问权限。获得 IP 不代表 MQTT 或 HTTP 服务器已可达，业务层还需进行 DNS、TLS、认证和连接状态管理。网络事件回调向工作任务通知状态即可，不宜在回调中进行大文件下载或耗时解析。

MQTT 发布订阅与 ESP-MQTT 事件处理见[MQTT 与 Modbus](../网络与通信/MQTT与Modbus.md)。
