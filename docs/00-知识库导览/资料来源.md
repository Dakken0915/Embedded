# 资料来源

本知识库中的页面经过重新归类和重写，按嵌入式系统的知识边界组织为可独立学习的专题。每个专题优先给出概念、接口、数据流、验证方法和故障边界，避免把零散摘录直接当作结论。

## 已整理主题

| 分类 | 知识边界 | 整理重点 |
| --- | --- | --- |
| 基础与工具 | 语言、内存、用户态、构建 | 资源所有权、错误路径、可重复构建 |
| Linux 与驱动 | 设备模型、子系统、并发 | 设备发现、数据流、生命周期和观测 |
| 硬件与接口 | 总线、时序、物理层、RTL | 协议约束、波形验证和驱动抽象 |
| 应用与框架 | 图像、UI、机器人通信 | 线程边界、数据契约和背压 |
| 工程实践 | 架构、测试、性能、复盘 | 从最小实验到可交付系统 |

涉及芯片手册、内核版本或工具版本时，仍应以项目实际文档和目标平台为准；专题页面中的实验步骤应在目标板上重新验证。
