# 学习方法

## 每个主题都回答四个问题

- **它解决什么问题？** 先写输入、输出和边界，不从 API 名称开始背。
- **数据如何流动？** 画出用户态、内核态、总线和设备之间的路径。
- **出错时看哪里？** 记录可观察信号：返回值、`errno`、`dmesg`、示波器、抓包或帧率。
- **换平台会变什么？** 把寄存器、引脚、设备树和业务逻辑分开记录。

## 从笔记到可复用知识

每个主题都可以补一张“最小实验”卡片：实验目的、硬件连接、编译命令、预期输出、失败现象和复盘。代码放在对应主题目录；涉及特定芯片或版本的结论，应注明适用边界。

## 一周学习循环

```text
概念阅读 → 最小代码 → 板上验证 → 记录观测 → 提炼边界条件 → 连接下一个主题
```

优先完成能测量的闭环，例如 GPIO 翻转、I2C 读寄存器、V4L2 采一帧、CAN 发收一帧，再扩展功能。
