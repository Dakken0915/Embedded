# 待扩展知识点

以下目录为后续整理预留。每个页面按专题细分，适合持续添加概念图、最小实验、板级验证和故障记录。现有笔记覆盖较少的部分也明确标出，避免与已整理内容混在一起。

| 分支 | 子主题 |
| --- | --- |
| MCU 与 RTOS | 启动时钟、中断 DMA、FreeRTOS 调度与同步 |
| 系统启动与构建 | U-Boot、内核启动、Rootfs、设备树、Buildroot/Yocto |
| 驱动子系统 | SPI/UART、时钟电源、PWM/ADC、存储、网络、音视频 |
| 网络与通信 | TCP/IP、Socket、MQTT、Modbus、Wi-Fi/Bluetooth |
| 调试与可靠性 | 性能分析、内存问题、Crash/Panic、OTA 与安全 |

占位目录中的清单是建议记录范围，不代表当前已有完整结论。补充时注明芯片型号、内核/SDK 版本和验证环境。
