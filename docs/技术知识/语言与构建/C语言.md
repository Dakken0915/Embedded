## C语言中使用汇编指令

```C
 __asm {
    MOV R0, #0x12       // 立即数给R0
    MOV R1, #0x34
    ADD R2, R1, R0      // R2 = R1 + R0
 }
```



## strstr 

功能：在一个字符串里，查找另一个字符串第一次出现的位置。

```C
strstr(原始字符串, 要找的内容);
```

返回值

1. 找到子串：返回 子串第一次出现位置的指针。
2. 未找到子串：返回 NULL。
3. 若子串为空字符串：直接返回原字符串首指针。



## strchr 

作用：在一个字符串里，查找第一次出现的某个字符

```C
char *strchr(const char *str, int character);
```

返回值

1. 找到字符：返回 该字符第一次出现位置的指针
2. 未找到字符：返回 **`NULL`**
3. 查找的是 字符串结束符 `\0` 时，也能找到，返回指向 `\0` 的指针



## strcat

功能：把一个字符串拼接到另一个字符串的末尾。

```C
strcat(字符数组1, 字符串2);
```

返回值

1. 返回字符数组 1 的起始地址。
2. 拼接后，字符数组 1 里存放最终结果。



## strcpy

功能：把源字符串完整复制到目标字符数组，连带末尾`\0`一并拷贝。

```C
strcpy(目标字符数组, 源字符串);
```

返回值

1. 返回目标字符数组起始地址。
2. 复制完成后目标数组存储完整字符串。
3. 无长度校验，源字符串超出数组容量会发生内存溢出。



## strncpy

功能：限制拷贝字节数，最多拷贝 n 字节源数据到目标内存。

```c
strncpy(目标字符数组, 源字符串, 拷贝最大长度n);
```

返回值

1. 返回目标字符数组起始地址。
2. 源串长度小于 n 时，剩余内存补 `\0`；源串长度大于等于 n 时，不自动添加结束符。
3. 使用后建议手动给末尾赋值 `\0`，防止产生非法无终止字符串。



## strtoul

功能：按指定进制，把数字字符串转无符号长整型，可获取转换截止位置。

```C
strtoul(字符串首地址, 结束字符二级指针, 进制base);
```

**参数**

1. 字符串首地址：待转换数字串
2. endptr：传出第一个非法字符地址，填 NULL 则丢弃
3. base：2~36 固定进制；0 自动识别 8/10/16 进制

**返回值**

1. 正常：转换得到的`unsigned long`
2. 无数字：返回 0
3. 溢出：返回`ULONG_MAX`，errno 设为 ERANGE



## memset

功能：将一段内存的内容全部设置为指定的值，常用于**数组 / 结构体清零**。

```c
memset(地址, 值, 长度);
```

返回值

1. 返回指向目标内存起始地址的指针。
2. 最常用：值写 0，代表把内存全部清零。



## memcpy

```c
void *memcpy(
    void *dest,        // 目标地址
    const void *src,   // 源地址
    size_t n           // 要复制的字节数
);
```



## memmove

```
void *memmove(void *dest, const void *src, size_t n);
```

和 memcpy 一样，但支持内存重叠，更安全

内存重叠 = 源数据区域 和 目标数据区域 有一部分是同一块内存。

解决内存重叠方式

- 不重叠 → 从前向后拷贝
- 重叠 → 从后向前拷贝，避免覆盖



## sprintf

功能：按照指定格式，把各类数据格式化存入目标字符数组。

```C
sprintf(字符数组, 格式串, 参数...);
```

返回值

1. 返回成功写入的有效字符个数（不含末尾 '\0'）。
2. 格式化拼接结果保存在第一个字符数组中。



## snprintf

功能：限定最大写入长度，格式化内容存入字符数组，防止缓冲区溢出。

```C
snprintf(字符数组, 缓冲区大小, 格式串, 参数...);
```

返回值

1. 返回理论需要的字符总数（超出容量也会返回完整长度）。
2. 实际最多存入「缓冲区大小 - 1」个字符，末尾自动补 '\0'。



## 标准库取整函数

需头文件：`#include <math.h>`

| 函数      | 作用     | 示例 (3.6) | 示例 (-3.6) |
| :-------- | :------- | :--------- | :---------- |
| `floor()` | 向下取整 | 3          | -4          |
| `ceil()`  | 向上取整 | 4          | -3          |
| `round()` | 四舍五入 | 4          | -4          |

示例代码：

```C
#include <stdio.h>
#include <math.h>

int main(void) {
    double val = 3.56;
    int a = floor(val);
    int b = ceil(val);
    int c = round(val);

    return 0;
}
```





## 浮点数计算

### 单精度浮点数

> 总 32 位 = 符号位 (1bit) + 阶码 (8bit) + 尾数 (23bit)
>
> 符号位 S：`0=正数`，`1=负数`
>
> 阶码 E：8 位，偏移量 = 127，真实指数 `e = E - 127`
>
> 尾数 M：23 位，隐含整数位 `1`，有效数字：`1.M`

### 双精度浮点数

> 总 64 位 = **符号位 (1bit) + 阶码 (11bit) + 尾数 (52bit)**
>
> 偏移量 = 1023，真实指数 `e = E - 1023`
>
> 换算公式
>
> `V = (-1)^S × (1.M)₂ × 2^e`
>
> `e = 阶码真值 = 阶码二进制值 - 偏移量`





## 八股

static 关键字的作用

> 修饰局部变量时，将局部变量存储在 .data段，延长变量的生命周期，函数退出时不销毁且只会被初始化一次
>
> 修饰全局变量和函数时，表示变量和函数的作用域限定于本文件内，不可以被外部引用

volatile 关键字的作用

> 告诉编译器不要优化被修饰变量，变量的值易被修改（比如中断修改，硬件修改），每次读取的时候从内存当中读取，不要从寄存器当中读取

数组和链表的区别

> 数组是连续一块内存，链表内存分散，靠指针串连起来
>
> 数组可以直接访问，链表遍历节点访问

指针和数组的关系

> 数组是一块连续的内存，指针是存放内存地址的变量
>
> 数组名大多数情况退化为首元素指针，但 sizeof、& 操作时不退化
>
> ```C++
> &arr + 1   // 移动的不是数组元素类型的大小，是整个数组的大小
> ```

编译流程

> 预处理 -> 编译 -> 汇编 -> 链接
>
> 预处理：删除注释，宏展开 + 文本替换，处理条件编译
>
> 编译：做语法，语义检查，翻译成汇编代码
>
> 汇编：把汇编指令翻译成机器指令，生成目标文件
>
> 链接：多个 .o 文件合并

声明和定义区别

> 声明是告诉编译器这个符号的名字类型，不分配内存
>
> 定义是给符号分配内存：变量会开辟空间，函数会生成函数体代码

二级指针什么时候用？举个实际场景

> 当函数需要修改【一级指针变量本身】的时候，就用二级指针

`sizeof`

> sizeof 是编译期运算符。绝大多数情况，编译器在编译阶段直接算出结果，替换成常数，运行时不再计算
> sizeof 参数可以是常量
> 结构体的 sizeof 大小**强烈依赖内存对齐**，对齐会增加 padding 填充字节







## 笔试

标识符可以以字母或下划线开头，不能以数字开头，不能是关键字。只能由数字、字母、下划线构成



% 两边都必须是整型



`const int* p`：常量指针，p指向的内容不能修改（可以通过其他指针进行修改），p的指向可以修改

`int* const p`：指针常量，指针的指向不可以修改，但是指向的内容可以修改



```C
/* 内存拷贝 */
void memcpy(char* dest, char void* src, size_t n) {
    if(dest == NULL || src == NULL)
        return NULL;
    if(dest > src && dest < src + n) {
        for(int i = n - 1; i >= 0; i--) {
            dest[i] = src[i];
        }
    }
    else {
        for(int i = 0; i < n; i++) {
            dest[i] = src[i];
        }
    }
}
```



浮点数零值比较

```C
const float epsilon = 1e-5f;
if(x >= -epsilon && s <= epsilon)   /* 阈值误差范围内，认为是 0 */
```



有符号数和无符号数混合运算时，有符号数会隐式转为无符号数再计算

- **signed int 溢出**：属于未定义行为 (UB)，编译器可以随便优化，结果不可靠。
- **unsigned int 溢出**：定义良好，按模 `2^N` 取余（回绕）



形参是局部变量，只能是变量，不能是常量或表达式



%15s 表示输出占 15 个空格的位置，并且右对齐，左边多余的位置补空格
%-5s 表示输出占 5 个空格的位置，并且左对齐，右边多余的位置补空格



以字符串形式初始化的，编译器会自动在末尾添加 "\0" 作为字符串结束符，区别于以数组形式初始化



scanf中的格式控制符不能指明浮点数的精度



x86 架构使用小端序存储方式，char* 类型指针按字节访问内存

在小端序中，低位字节存储在低地址，高位字节存储在高地址。因此 0xabcd1234 在内存中的存储顺序为从低地址到高地址依次是: 34 12 cd ab

```C
int a = 0xabcd1234; 
char b = ((char*)&a)[0];  /* b是 34 */
```
