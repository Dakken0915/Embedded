# Linux 用户态

## 需要串起来的对象

进程拥有地址空间和文件描述符；线程共享地址空间但共享数据需要同步；`mmap` 可以映射文件、设备或共享内存；系统调用是用户态与内核态的稳定边界。

## 内存选择

小对象通常使用 `malloc`，大块或共享区域可考虑 `mmap`，DMA 缓冲区必须服从设备的物理连续性与缓存一致性要求。不要只按申请大小选择 API，要同时看生命周期、访问方和对齐约束。

## 调试清单

先检查返回值和 `errno`，再用 `strace` 看系统调用，用 `top`/`/proc` 看资源，用 `dmesg` 看驱动与内核错误。遇到偶现问题，记录时间、线程、设备节点和输入数据，避免只凭最后一条日志猜原因。
