# C 与 C++ 核心

## C：直接面对内存

重点不是 API 数量，而是确认对象的生命周期、大小和对齐。字符串函数要处理 `NULL`、长度和终止符；位域、强制类型转换和结构体布局要考虑编译器与 ABI。

## C++：用类型管理资源

- 用 RAII 绑定文件描述符、锁和映射区域的释放。
- 有裸指针所有权时，明确深拷贝、移动或禁止拷贝，避免 double free。
- `vector` 适合连续缓存，`deque` 适合两端队列，`unordered_map` 适合平均 O(1) 查找，但实时路径要关注扩容和哈希抖动。
- 多线程共享对象时，先划分所有权，再选择互斥锁、原子变量或消息队列。

## 嵌入式取舍

动态分配并非绝对禁止，但启动期分配、固定容量容器和静态缓冲更容易给出内存上界。把异常、日志和分配失败策略写进接口，而不是藏在调用方的假设里。
