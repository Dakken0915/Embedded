# 基础与工具路线

这条路线解决“能写、能编、能在 Linux 上定位问题”三个基本能力。

## 主题顺序

1. **C**：指针、内存布局、字符串、位操作和未定义行为。
2. **C++**：RAII、拷贝语义、模板、STL 容器和线程安全边界。
3. **Linux 用户态**：进程、线程、文件描述符、`mmap`、系统调用和内存分配。
4. **构建与脚本**：Makefile 依赖图、交叉编译、Shell 参数和自动化验证。

嵌入式代码要优先建立资源所有权和错误路径：谁申请、谁释放；谁打开设备、谁关闭；系统调用失败时返回什么，是否需要重试。

## 最小练习

写一个 C 程序通过 `open/read/write/ioctl` 访问设备文件，再用 Makefile 同时生成 native 和 ARM 目标。用 `strace` 查看系统调用，用 `gdb` 检查指针和线程栈。
