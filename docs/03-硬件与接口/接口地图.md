# 硬件与接口地图

把接口分成三层看：**物理层**解决电平、阻抗、上拉和连接；**链路层**解决帧、仲裁、校验和重传；**驱动层**把寄存器或控制器能力暴露给软件。

| 接口 | 典型问题 | 验证工具 |
| --- | --- | --- |
| I2C | 地址、ACK、重复起始、上拉 | 示波器、逻辑分析仪、`i2cdetect` |
| CAN | 位时序、终端电阻、仲裁、错误状态 | CAN 分析仪、`candump` |
| USB | 枚举、描述符、端点、传输类型 | `lsusb`、USB 抓包 |
| GPIO | 复用、方向、有效电平、中断 | 示波器、`gpioget` |
| V4L2 | 格式、缓冲、帧率、带宽 | `v4l2-ctl`、`dmesg` |

先验证物理层，再验证协议，最后定位驱动和应用。这样能避免把电气问题误判成软件 bug。
