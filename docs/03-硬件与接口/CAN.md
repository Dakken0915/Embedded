# CAN 总线

CAN 使用差分信号和非破坏性仲裁。帧 ID 越小优先级越高，节点发送隐性位时若读到显性位就退出仲裁，因此高优先级消息不会破坏低优先级消息的已发送部分。

## 需要掌握的量

- 标准帧/扩展帧、数据帧/远程帧、ACK、CRC、错误帧和位填充。
- 位时间由同步段、传播段、相位缓冲段构成；采样点和总线长度共同限制波特率。
- 错误主动、错误被动和总线关闭由发送/接收错误计数器推动，恢复策略要在系统层定义。

调试先检查 120Ω 终端、电平和收发器，再检查 bit timing、过滤器和应用帧定义。Linux SocketCAN 让应用通过标准 socket 接口使用 CAN，便于替换硬件控制器。
