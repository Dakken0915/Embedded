# FPGA 与 Verilog

FPGA 设计从时钟和复位开始，再进入组合逻辑、时序逻辑、FIFO、状态机和接口时序。`wire` 表示连线，`reg/logic` 表示过程块中保存的值；真正需要关注的是组合/时序语义和综合后的硬件。

## 实践要点

- 用同步设计和明确的时钟域交叉方案处理亚稳态。
- 状态机采用状态寄存器、次态逻辑、输出逻辑的清晰结构。
- 异步 FIFO 用 Gray code 传递读写指针，跨域信号使用两级同步。
- 约束文件决定引脚、时钟和时序边界，仿真通过不等于板上时序可靠。

可继续扩展的专题包括时钟约束、跨时钟域、PWM、ADC、UART 和板级调试。
