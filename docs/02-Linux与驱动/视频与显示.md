# 视频与显示

## V4L2 采集链路

打开 `/dev/videoX` 后，按能力查询、格式协商、申请缓冲、映射、入队、启动流、轮询、出队、处理、重新入队的顺序工作。常见错误是忽略 `bytesperline`、像素格式、缓冲区生命周期或 `poll` 超时。

## 显示链路

LCD/Framebuffer 关注像素格式、stride、分辨率、双缓冲和 DMA 一致性。采集线程不应直接阻塞在显示设备上；用有界队列或最新帧策略隔离生产者和消费者，并用帧率、延迟和丢帧数验证优化效果。

完整采集路径需要同时理解用户态 V4L2 API、驱动缓冲区队列、DMA 带宽和显示刷新节拍；调试时分别测量采集、处理和显示延迟。
