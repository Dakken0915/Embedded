# 总线与输入

## I2C

I2C 是带地址的半双工总线。一次典型读操作是写寄存器地址后重复起始，再读数据；要确认从设备地址、上拉、电平、时钟频率和 ACK。驱动中使用 `i2c_client` 和 SMBus/I2C API，不要把时序细节复制到每个业务模块。

## Input

输入子系统把按键、触摸和鼠标统一成事件流：设备驱动上报事件，handler 或用户态读取 `/dev/input/event*`。按键消抖可以放硬件、定时器或状态机中，但必须明确时间窗口，不能用阻塞 sleep 掩盖抖动。

## USB

USB 设备由描述符、配置、接口和端点组成。分析枚举失败时，从供电和速度协商开始，再检查描述符、端点方向、传输类型和驱动匹配表。
