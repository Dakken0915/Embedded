## 形式参数

形式参数是在函数定义中声明的局部对象，每次调用都具有独立的自动存储期。C 语言按值传递参数；修改形参本身不会修改调用方的实参对象。指针形参仍按值传递，但可以通过指针访问和修改所指对象。实参可以是变量、常量或表达式，其类型须满足参数转换规则。

```c
#include <stdio.h>

static void changeValue(int value)
{
    value = 20;
    printf("形参：%d\n", value);
}

static void changeObject(int *value)
{
    *value = 20;
}

int main(void)
{
    int number = 10;
    changeValue(number);
    printf("按值传递后：%d\n", number);  /* 10 */
    changeObject(&number);
    printf("通过指针修改后：%d\n", number);  /* 20 */
    return 0;
}
```

## 函数指针与回调

函数指针的参数及返回类型必须与实际函数兼容。上下文指针可以传递实例状态，回调能否阻塞由调用者所在上下文决定；ISR 回调不能直接沿用允许睡眠的任务回调实现。

```c
#include <stddef.h>
#include <stdint.h>
typedef void (*SampleCallback)(void *context, uint16_t value);
struct SampleSink {
    SampleCallback callback;
    void *context;
};
void dispatchSample(const struct SampleSink *sink, uint16_t value)
{
    if (sink != NULL && sink->callback != NULL) {
        sink->callback(sink->context, value);
    }
}
```

回调注册者须保证 context 在所有在途回调结束前有效；取消注册与释放状态之间需要同步。递归依赖终止条件和每层栈容量，尾调用优化不受 C 标准保证。

## 可变参数与格式匹配

`printf` 使用格式串约定参数类型，通过可变参数机制读取实参。默认参数提升将 float 提升为 double，将相应小整数类型提升为 int 或 unsigned int；格式不匹配可能产生未定义行为。

```c
#include <stdarg.h>
#include <stdio.h>
int logFormat(const char *format, ...)
{
    va_list arguments;
    va_start(arguments, format);
    int result = vprintf(format, arguments);
    va_end(arguments);
    return result;
}
```

每个 `va_start` 或 `va_copy` 必须匹配 `va_end`；可变参数列表没有可自动查询的元素数量或类型。`scanf` 的指针类型与 `printf` 的值类型规则不同：`%f` 接收 float 指针，`%lf` 接收 double 指针；不能在 scanf 中用精度限制小数位数。

## 宏和 inline

宏在预处理阶段展开，参数可能被求值多次；函数有类型检查和调用语义。`inline` 不保证实际展开，编译器也可以内联未标注的函数。C 头文件中的小型内部辅助函数常写作 `static inline`，避免将 C 的外部 inline 定义规则与 C++ 混用。

## 串口标准 I/O 适配

重定向接口取决于 C 库与工具链。部分 Arm C 库可覆写 fputc/fgetc，newlib 常通过 `_write` 等底层接口适配；MicroLIB 不是所有工程的必要条件。下例仅适用于采用该 fputc 适配约定的 C 库，板级 `uartWriteByte` 须实现超时并报告失败。

```c
#include <stdint.h>
#include <stdio.h>
extern int uartWriteByte(uint8_t byte);
int fputc(int character, FILE *stream)
{
    (void)stream;
    if (uartWriteByte((uint8_t)character) != 0) {
        return EOF;
    }
    return (unsigned char)character;
}
```

多任务日志应避免逐字符无保护地交错输出；中断中同步轮询输出会扩大中断延迟。换行是否转换成 CRLF 应由接口约定决定，不能重复转换。
