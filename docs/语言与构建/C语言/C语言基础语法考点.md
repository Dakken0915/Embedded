# C 语言基础语法考点

本文以 C11 为基础，涵盖类型限定、指针声明、数值表示与运算规则；C++ 和编译器扩展的不同语义另行注明。

## 基础语法补充

- 函数定义中的形式参数是局部变量，具有自动存储期；C 按值传递参数，修改形参本身不会修改调用方的实参。
- `printf` 中，`%15s` 表示最小字段宽度为 15，右对齐、左侧补空格；`%-5s` 表示最小字段宽度为 5，左对齐、右侧补空格。字符串超过字段宽度时完整输出，不会因此截断。
- `char a[] = "abc";` 自动包含末尾结束符 `'\0'`；`char b[] = {'a', 'b', 'c'};` 不包含结束符。C 中若显式指定的数组长度刚好只够字符，例如 `char c[3] = "abc";`，也不会保留结束符。

## const char * 与 char const *

`const char *p` 和 `char const *p` 类型完全相同，均声明“指向 const 限定 char 的指针”。`const` 在这里限定所指字符，而不是指针对象本身：可以让 `p` 指向其他有效对象，但不能通过 `*p` 或 `p[i]` 修改字符。这不表示所指对象一定在定义时就是 const，也不保证它不会被其他合法访问路径修改。

| 声明 | 指针对象能否重新赋值 | 能否通过该指针修改字符 |
| --- | --- | --- |
| `char *p` | 可以 | 所指对象本身可写且访问有效时可以 |
| `const char *p` | 可以 | 不可以 |
| `char const *p` | 可以，与上一项等价 | 不可以 |
| `char *const p` | 不可以 | 所指对象本身可写且访问有效时可以 |
| `const char *const p` | 不可以 | 不可以 |

`char const *const p` 与最后一行也等价。判断限定位置时，要区分 `*` 左侧的所指类型限定和 `*` 右侧的指针对象限定；不能把 `const char *` 与 `char *const` 混为一谈。


```c
int main(void)
{
    char first[] = "abc";
    char second[] = "xyz";
    const char *p = first;
    char const *q = p;          /* 与 p 的指针类型相同 */
    char *const fixed = first; /* 指针不可重新赋值，数组仍可写 */
    const char *const view = first;

    first[0] = 'A';            /* 合法：实际数组不是 const 对象 */
    fixed[1] = 'B';            /* 合法：限制的是 fixed 的地址值 */
    p = second;               /* 合法：p 本身不是 const 指针 */
    ++q;                      /* 合法：q 现在指向 first[1] */

    /* p[0] = 'X'; */          /* 约束违反：不能通过 p 写入 */
    /* fixed = second; */      /* 约束违反：不能修改 fixed */

    return p[0] == 'x' && q[0] == 'B' && view[0] == 'A' ? 0 : 1;
}
```

字符串字面量另有规则：C 中 `"abc"` 的类型为字符数组，但尝试修改其内容仍是未定义行为。因此 `char *p = "abc";` 在 C 中可以通过类型检查，却不能据此执行 `p[0] = 'A'`；通常应写 `const char *p = "abc";`，让类型系统限制误写。需要可修改内容时使用 `char text[] = "abc";`，它建立独立数组并复制初始字符。


## 标准库取整函数

取整函数依赖 `<math.h>`，下表列出 double 版本；它们返回 double 而非 int。`round` 的中点规则为远离零，例如 `round(2.5) == 3.0`、`round(-2.5) == -3.0`，不是舍入到最近偶数。

| 函数      | 作用     | 示例 (3.6) | 示例 (-3.6) |
| :-------- | :------- | :--------- | :---------- |
| `floor()` | 向下取整 | 3          | -4          |
| `ceil()`  | 向上取整 | 4          | -3          |
| `round()` | 最近整数，中点远离零 | 4          | -4          |

以下 C11 完整示例仅处理有限且较小的输入，不进行浮点到 int 的转换，避免额外的整数范围问题。Linux 常见编译命令为 `cc -std=c11 rounding.c -lm -o rounding`；裸机需确认数学库支持。若业务需要转成整数，须先排除 NaN/无穷并检查结果可表示。

```C
#include <math.h>

int main(void) {
    double val = 3.56;
    double a = floor(val);
    double b = ceil(val);
    double c = round(val);

    return a == 3.0 && b == 4.0 && c == 4.0 &&
           round(2.5) == 3.0 && round(-2.5) == -3.0 ? 0 : 1;
}
```






## 浮点数计算

### 单精度浮点数

> 总 32 位 = 符号位 (1bit) + 阶码 (8bit) + 尾数 (23bit)
>
> 符号位 S：`0=正数`，`1=负数`
>
> 阶码 E：8 位，偏移量 = 127，真实指数 `e = E - 127`
>
> 尾数 M：23 位，隐含整数位 `1`，有效数字：`1.M`

### 双精度浮点数

> 总 64 位 = **符号位 (1bit) + 阶码 (11bit) + 尾数 (52bit)**
>
> 偏移量 = 1023，真实指数 `e = E - 1023`
>
> 换算公式
>
> `V = (-1)^S × (1.M)₂ × 2^e`
>
> `e = 阶码真值 = 阶码二进制值 - 偏移量`

## 特殊浮点值与误差

上述隐藏整数位为 1 的公式仅用于 IEEE 754 正规数。指数全零涉及零与次正规数；指数全一涉及无穷与 NaN。C 标准不要求所有实现的 float 都采用 binary32，应结合 `float.h` 与平台约定。

浮点误差判断需要绝对容差与相对容差。近零判断可以使用 `fabsf(x) <= tolerance`；容差应由量纲和测量精度确定，而不是统一使用一个常数。NaN 与自身比较不相等，应按业务规则显式处理。

## 整数提升与溢出

`%` 的两个操作数须为整数，除数不能为零；有符号最小值除以 -1 也可能不可表示。有符号溢出是未定义行为，无符号运算按模回绕，但无符号回绕仍可能造成长度校验缺陷。

有符号与无符号混合运算遵循整数提升及通常算术转换，并非任何情况下都统一转为无符号。例如当较高等级有符号类型能表示另一类型所有值时，可以转为该有符号类型。

```c
#include <stddef.h>
#include <stdint.h>
int checkedAddSize(size_t a, size_t b, size_t *result)
{
    if (result == NULL || a > SIZE_MAX - b) {
        return -1;
    }
    *result = a + b;
    return 0;
}
```
