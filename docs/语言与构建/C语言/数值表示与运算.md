## 标准库取整函数

需头文件：`#include <math.h>`

| 函数      | 作用     | 示例 (3.6) | 示例 (-3.6) |
| :-------- | :------- | :--------- | :---------- |
| `floor()` | 向下取整 | 3          | -4          |
| `ceil()`  | 向上取整 | 4          | -3          |
| `round()` | 四舍五入 | 4          | -4          |

示例代码：

```C
#include <stdio.h>
#include <math.h>

int main(void) {
    double val = 3.56;
    int a = floor(val);
    int b = ceil(val);
    int c = round(val);

    return 0;
}
```






## 浮点数计算

### 单精度浮点数

> 总 32 位 = 符号位 (1bit) + 阶码 (8bit) + 尾数 (23bit)
>
> 符号位 S：`0=正数`，`1=负数`
>
> 阶码 E：8 位，偏移量 = 127，真实指数 `e = E - 127`
>
> 尾数 M：23 位，隐含整数位 `1`，有效数字：`1.M`

### 双精度浮点数

> 总 64 位 = **符号位 (1bit) + 阶码 (11bit) + 尾数 (52bit)**
>
> 偏移量 = 1023，真实指数 `e = E - 1023`
>
> 换算公式
>
> `V = (-1)^S × (1.M)₂ × 2^e`
>
> `e = 阶码真值 = 阶码二进制值 - 偏移量`

## 特殊浮点值与误差

上述隐藏整数位为 1 的公式仅用于 IEEE 754 正规数。指数全零涉及零与次正规数；指数全一涉及无穷与 NaN。C 标准不要求所有实现的 float 都采用 binary32，应结合 `float.h` 与平台约定。

浮点误差判断需要绝对容差与相对容差。近零判断可以使用 `fabsf(x) <= tolerance`；容差应由量纲和测量精度确定，而不是统一使用一个常数。NaN 与自身比较不相等，应按业务规则显式处理。

## 整数提升与溢出

`%` 的两个操作数须为整数，除数不能为零；有符号最小值除以 -1 也可能不可表示。有符号溢出是未定义行为，无符号运算按模回绕，但无符号回绕仍可能造成长度校验缺陷。

有符号与无符号混合运算遵循整数提升及通常算术转换，并非任何情况下都统一转为无符号。例如当较高等级有符号类型能表示另一类型所有值时，可以转为该有符号类型。

```c
#include <stddef.h>
#include <stdint.h>
int checkedAddSize(size_t a, size_t b, size_t *result)
{
    if (result == NULL || a > SIZE_MAX - b) {
        return -1;
    }
    *result = a + b;
    return 0;
}
```

有符号整数表示与语言版本有关；常见 C11 平台采用补码，但不能把“所有 C 实现都必须采用补码”作为跨版本结论。
