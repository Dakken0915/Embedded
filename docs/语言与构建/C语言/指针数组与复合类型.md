# 指针、数组与复合类型

## 指针和数组

数组由连续的同类型元素组成，指针对象保存地址值。数组表达式在多数使用场景转换为首元素指针，但作为 `sizeof`、一元 `&` 的操作数等情形不发生这种转换。数组形参会调整为指针形参，无法在函数内通过 `sizeof` 找回调用方数组的容量。

```c
#include <stddef.h>

int values[4] = {1, 2, 3, 4};
int *element = values;
int (*whole)[4] = &values;
/* element + 1 前进一个 int，whole + 1 前进整个数组的大小。 */
size_t count = sizeof(values) / sizeof(values[0]);
```

数组支持常数时间下标定位；链表通过链接访问节点，随机定位通常需要遍历。链表插入删除在已知位置且满足链接条件时可避免搬动后续元素，但还需要分配、缓存局部性及指针空间成本。

## const 与多级指针

`const int *p` 可以改变 p，但不能通过 p 修改所指 int；`int *const p` 不能改变 p，但可修改其所指可写 int。`const int *const p` 同时限制两者。

`const char *` 与 `char const *` 的等价关系、指针对象与所指对象的限定，以及去掉 const 后能否修改的完整示例，见 [C 语言基础语法考点](./C语言基础语法考点.md)。

二级指针适用于修改调用方指针对象。以下函数要求 output 非空，成功后调用方取得堆内存所有权；失败不改变原指针。

```c
#include <stddef.h>
#include <stdlib.h>

int allocateBytes(unsigned char **output, size_t length)
{
    if (output == NULL || length == 0) {
        return -1;
    }
    unsigned char *memory = malloc(length);
    if (memory == NULL) {
        return -1;
    }
    *output = memory;
    return 0;
}
```

未初始化的指针可能具有不确定值；悬空指针指向生命周期已结束的对象。`free(p); p = NULL;` 只清除此变量，不会清除其他别名，也不能使重复释放或越界访问安全。

## 结构体、联合体与对齐

结构体各成员具有独立存储，成员间及尾部可能包含 padding；其对齐和大小由目标 ABI 决定。联合体成员共享存储，大小至少容纳最大成员，并满足对齐。不能把某个平台的布局当作网络协议布局。

```c
#include <stddef.h>
#include <stdint.h>

struct Sample {
    uint8_t status;
    uint32_t timestamp;
    uint16_t value;
};
/* sizeof(struct Sample)、_Alignof(struct Sample)、offsetof(...) 用于核对布局。 */
```

`#pragma pack` 是实现相关控制，可能产生非对齐访问、额外指令乃至硬件异常。位域的分配方向、跨存储单元布局等取决于实现，不适合作为可移植的线缆协议解析。解析外部数据应使用字节和显式移位。

```c
#include <stdint.h>
uint16_t readBigEndian16(const uint8_t data[2])
{
    return (uint16_t)(((uint16_t)data[0] << 8) | data[1]);
}
```

C99 柔性数组成员写作 `unsigned char data[]`，位于具有其他命名成员的结构体末尾；零长度数组 `data[0]` 是部分编译器扩展。分配柔性数组前应检查 `sizeof(header) + payloadLength` 是否溢出。

## sizeof 与字节序

`sizeof` 的结果类型为 `size_t`，通常不求值操作数；变长数组类型等情形可能需要运行时求值。结构体大小包括尾部填充，指针大小取决于数据模型。

通过 `unsigned char *` 观察对象表示是合法的，但不能据此假设所有机器都是小端。

```c
#include <stdint.h>
int isLittleEndian(void)
{
    const uint32_t value = UINT32_C(0x01020304);
    const unsigned char *bytes = (const unsigned char *)&value;
    return bytes[0] == 0x04;
}
```

## 动态内存与碎片

`malloc` 不初始化内容，`calloc` 清零分配的字节，`realloc` 可能移动对象。扩容失败时旧对象仍然有效，不能直接覆盖唯一的原指针；乘法和加法容量计算也必须检查溢出。

```c
#include <stdint.h>
#include <stdlib.h>
int resizeIntegers(int **data, size_t count)
{
    if (data == NULL || count == 0 || count > SIZE_MAX / sizeof(int)) {
        return -1;
    }
    int *replacement = realloc(*data, count * sizeof(int));
    if (replacement == NULL) {
        return -1;
    }
    *data = replacement;
    return 0;
}
```

外部碎片表示空闲总量足够但缺少所需连续块；内部碎片来自对齐或分配粒度。固定块内存池可控制分配粒度和时间，静态分配可减少运行时失败，但都需要容量规划和所有权规则。
