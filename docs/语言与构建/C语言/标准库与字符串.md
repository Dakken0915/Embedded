## strstr 

功能：在一个字符串里，查找另一个字符串第一次出现的位置。

```C
strstr(原始字符串, 要找的内容);
```

返回值

1. 找到子串：返回 子串第一次出现位置的指针。
2. 未找到子串：返回 NULL。
3. 若子串为空字符串：直接返回原字符串首指针。




## strchr 

作用：在一个字符串里，查找第一次出现的某个字符

```C
char *strchr(const char *str, int character);
```

返回值

1. 找到字符：返回 该字符第一次出现位置的指针
2. 未找到字符：返回 **`NULL`**
3. 查找的是 字符串结束符 `\0` 时，也能找到，返回指向 `\0` 的指针




## strcat

功能：把一个字符串拼接到另一个字符串的末尾。

```C
strcat(字符数组1, 字符串2);
```

返回值

1. 返回字符数组 1 的起始地址。
2. 拼接后，字符数组 1 里存放最终结果。




## strcpy

功能：把源字符串完整复制到目标字符数组，连带末尾`\0`一并拷贝。

```C
strcpy(目标字符数组, 源字符串);
```

返回值

1. 返回目标字符数组起始地址。
2. 复制完成后目标数组存储完整字符串。
3. 无长度校验，源字符串超出数组容量会发生内存溢出。




## strncpy

功能：限制拷贝字节数，最多拷贝 n 字节源数据到目标内存。

```c
strncpy(目标字符数组, 源字符串, 拷贝最大长度n);
```

返回值

1. 返回目标字符数组起始地址。
2. 源串长度小于 n 时，剩余内存补 `\0`；源串长度大于等于 n 时，不自动添加结束符。
3. 使用后建议手动给末尾赋值 `\0`，防止产生非法无终止字符串。




## strtoul

功能：按指定进制，把数字字符串转无符号长整型，可获取转换截止位置。

```C
strtoul(字符串首地址, 结束字符二级指针, 进制base);
```

**参数**

1. 字符串首地址：待转换数字串
2. endptr：传出第一个非法字符地址，填 NULL 则丢弃
3. base：2~36 固定进制；0 自动识别 8/10/16 进制

**返回值**

1. 正常：转换得到的`unsigned long`
2. 无数字：返回 0
3. 溢出：返回`ULONG_MAX`，errno 设为 ERANGE




## memset

功能：将一段内存的内容全部设置为指定的值，常用于**数组 / 结构体清零**。

```c
memset(地址, 值, 长度);
```

返回值

1. 返回指向目标内存起始地址的指针。
2. 最常用：值写 0，代表把内存全部清零。




## memcpy

```c
void *memcpy(
    void *dest,        // 目标地址
    const void *src,   // 源地址
    size_t n           // 要复制的字节数
);
```




## memmove

```
void *memmove(void *dest, const void *src, size_t n);
```

memcpy 要求源和目标不重叠；memmove 以如同经过临时缓冲区的效果处理重叠。

内存重叠 = 源数据区域 和 目标数据区域 有一部分是同一块内存。

解决内存重叠方式

- 目标位于源区之后且存在重叠时，可从后向前复制。
- 目标位于源区之前时，可从前向后复制。

具体实现可能使用向量指令或临时存储，并不保证简单逐字节循环。无关对象指针不能随意用大小关系比较来编写通用 memmove。




## sprintf

功能：按照指定格式，把各类数据格式化存入目标字符数组。

```C
sprintf(字符数组, 格式串, 参数...);
```

返回值

1. 返回成功写入的有效字符个数（不含末尾 '\0'）。
2. 格式化拼接结果保存在第一个字符数组中。




## snprintf

功能：限定最大写入长度，格式化内容存入字符数组，防止缓冲区溢出。

```C
snprintf(字符数组, 缓冲区大小, 格式串, 参数...);
```

返回值

1. 返回理论需要的字符总数（超出容量也会返回完整长度）。
2. 容量大于零时，实际最多存入「缓冲区大小 - 1」个字符，末尾自动补 '\0'。




## printf 字段宽度

`%15s` 的字段宽度为 15，字符串在字段内右对齐，左侧不足的字符以空格补齐。

`%-5s` 的字段宽度为 5，字符串在字段内左对齐，右侧不足的字符以空格补齐。字段宽度是最小宽度，字符串长度超过字段宽度时不会被截断。

```c
printf("|%15s|\n", "CAN");  /* |            CAN| */
printf("|%-5s|\n", "CAN");  /* |CAN  | */
printf("|%5s|\n", "FreeRTOS");  /* |FreeRTOS|，不截断 */
printf("|%.5s|\n", "FreeRTOS"); /* |FreeR|，精度限制输出长度 */
```


## 字符串初始化

字符串字面量在字符序列末尾包含 `\0`。以字符串字面量初始化未指定长度或空间充足的字符数组时，结束符会一同写入：

```C
char text[] = "abc";       /* 实际占用 4 个字符空间：a、b、c、\0 */
char text2[3] = {'a', 'b', 'c'}; /* 不是以字符串形式初始化，没有 \0 */
```

字符数组若要作为 C 字符串使用，必须保证数组空间包含末尾的 `\0`。C 允许 `char text3[3] = "abc";`，此时容量恰好容纳三个有效字符，末尾没有结束符，不能作为以空字符结尾的字符串传入 `%s` 等接口。

## 有界格式化与错误处理

snprintf 返回负值表示编码等错误，非负返回值大于等于容量表示截断。容量为零时不写入结束符；源和目标重叠也不能因使用了 snprintf 就认为合法。

```c
#include <stdio.h>
int formatSensorId(char *output, size_t capacity, unsigned id)
{
    if (output == NULL || capacity == 0) return -1;
    int count = snprintf(output, capacity, "sensor-%u", id);
    if (count < 0 || (size_t)count >= capacity) return -1;
    return 0;
}
```

strcpy/strcat 须事先确认目标容量，strcat 还需目标已有合法结束符。strncpy 的长度参数表示最多写入数，不保证终止，且短源会补零。strtoul 应检查 errno、endptr、空输入、负号及目标范围，不能只判断返回值是否为零。memset 清零字节不意味着可移植地得到任意类型的空指针或任意对象的有效值。
