## 现代 C++ 特性（C++11 及以后）

C++11 是 C++ 发展史上的一个重要里程碑，引入了大量新特性，极大地改变了 C++ 的编程风格。后续的 C++14、C++17、C++20 等版本又不断完善和扩展。

### 1 智能指针（Smart Pointers）

- 解决 C 语言中手动管理内存导致的内存泄漏、野指针等问题
- `unique_ptr`（C++11）：独占所有权的智能指针
- `shared_ptr`（C++11）：共享所有权的智能指针，使用引用计数
- `weak_ptr`（C++11）：弱引用，不增加引用计数，用于解决 shared_ptr 的循环引用问题

### 2 右值引用与移动语义（C++11）

- 值类别需区分 lvalue、xvalue 与 prvalue；字符串字面量是数组左值，不能把所有字面量都归为右值
- 右值引用：`类型 &&引用名 = 右值;`
- 移动语义：将资源从一个对象转移到另一个对象，避免不必要的拷贝
- `std::move`：将左值转换为右值引用

### 3 Lambda 表达式（C++11）

- 匿名函数，用于编写简短的函数对象
- 语法：`[捕获列表](参数列表) -> 返回类型 { 函数体 }`
- 捕获列表：可以捕获外部变量
- 常用于 STL 算法的参数

捕获列表速查

| 写法     | 含义                       |
| :------- | :------------------------- |
| `[]`     | 不捕获任何外部变量         |
| `[&]`    | 以引用方式默认捕获所需的局部实体 |
| `[=]`    | 以值方式默认捕获所需的局部实体   |
| `[&obj]` | 只捕获 `obj`，用引用       |
| `[obj]` | 只捕获 `obj`，用值         |



### 4 范围 for 循环（C++11）

- 简化容器的遍历
- 语法：`for (auto &元素 : 容器) { 循环体 }`

### 5 类型推导增强

- `auto`：自动推导变量类型
- `decltype`（C++11）：推导表达式的类型
- `auto`返回值（C++14）：函数返回值自动推导

### 6 结构化绑定（C++17）

- 将元组、结构体等的成员绑定到多个变量
- 语法：`auto [a, b, c] = 元组/结构体;`

### 7 概念与约束（C++20）

- 用于限制模板参数的类型
- 语法：`template <概念名 T> 返回类型 函数名(参数列表) { 函数体 }`
- 提高模板代码的可读性和错误信息的清晰度

### 8 协程（C++20）

- 用于编写异步代码
- 语法：`co_await`、`co_yield`、`co_return`
- 简化异步编程模型

协程关键字不自动提供线程或事件循环；协程帧、promise、挂起点和调度器的生命周期需要由库与调用协议管理。constexpr 函数也可能在运行时执行，并非所有调用都在编译期求值。
