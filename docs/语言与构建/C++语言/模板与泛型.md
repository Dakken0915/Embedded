## 泛型编程与模板

泛型编程是 C++ 的另一大核心特性，允许编写与类型无关的通用代码，提高代码的复用性。

### 1 函数模板

- 语法：`template <typename T> 返回类型 函数名(参数列表) { 函数体 }`
- `typename`可以用`class`替代
- 编译器会根据实际参数类型生成对应的函数实例

```cpp
#include <iostream>

// 函数模板定义
template <typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    // 自动生成 int 版本
    std::cout << add(1, 2) << std::endl;
    
    // 自动生成 double 版本
    std::cout << add(1.5, 2.5) << std::endl;
    
    return 0;
}
```

### 2 类模板

- 语法：`template <typename T> class 类名 { 类定义 };`
- 类模板的成员函数通常也需要定义为模板函数
- 使用时需要显式指定模板参数：`类名<类型> 对象名;`

```cpp
#include <iostream>

// 类模板定义
template <typename T>
class Box {
private:
    T val;
public:
    void set(T v) { val = v; }
    T get() { return val; }
};

int main() {
    Box<int> b1;        // 必须写 <int>
    b1.set(100);
    std::cout << b1.get();   // 输出100
    return 0;
}
```

### 3 模板特化

**现有通用模板才能写特化模板**

- 针对特定类型提供模板的特殊实现
- 全特化：针对所有模板参数提供特化
- 偏特化：针对部分模板参数提供特化

```cpp
#include <iostream>

// 通用版本
template <typename T>
void print (T t) { std::cout << t; }

// 特化：只给 bool 特殊处理
template <>                         // 特殊处理不需要占位符
void print <bool> (bool t) {
    std::cout << (t ? "true" : "false");
}
```

### 4 可变参数模板（C++11）

- 允许模板接受任意数量和类型的参数

- 语法：`template <typename... Args> 返回类型 函数名(Args... args) { 函数体 }`

  **`...`**：代表**一包参数**（任意个数、任意类型）

  **`Args`**：类型的包（比如 `int, string, double`）

  **`args`**：数据的包（比如 `10, "abc", 3.14`）

```cpp
#include <iostream>

// 折叠表达式需要 C++17。
template <typename... Args>
void print(Args... args)
{
    (std::cout << ... << args) << std::endl;
}

int main() {
    print(1);            // 1个参数
    print(1, 2.5);       // 2个参数
    print(1, "A", 3.14); // 3个参数
    return 0;
}
```

函数模板不支持偏特化，可使用重载等机制；类模板支持相应偏特化。C++17 类模板实参推导适用于满足规则的构造，不代表每种类模板都必须显式填写全部实参。上面的折叠表达式属于 C++17，可变参数模板本身从 C++11 引入。
