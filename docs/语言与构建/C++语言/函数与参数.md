# 函数、参数与引用

## 重载与默认参数

函数重载按参数列表及相关语言规则区分，不能只凭返回类型重载。默认实参在调用点补入，不增加一个新的函数重载；默认值声明须满足作用域规则，不应在重复可见的声明中重复指定。

```cpp
#include <iostream>
void show(int value) { std::cout << value; }
void show(double value) { std::cout << value; }
void show(int value, int second) { std::cout << value << second; }
int add(int left, int right = 10) { return left + right; }
```

## 指针、引用与参数传递

引用必须绑定适当对象，通常不能重新绑定；但引用仍可能因对象销毁而悬空，不能把“引用不为空”误认为引用必然安全。指针允许空值、重新指向及在合法数组范围内的算术操作，适用于可选对象和显式所有权边界。

按值传参建立参数对象，const 引用可避免复制，但所引用对象必须在使用期间有效。返回局部自动对象的引用或指针会产生生命周期错误。

## inline 与函数模板

inline 的语言语义主要涉及定义与 ODR 规则，不保证更快或替代任何宏。类内定义成员通常隐式 inline；C++20 命名模块场景还需按模块规则理解。

```cpp
template <typename T>
T maximum(T left, T right)
{
    return left > right ? left : right;
}
```

函数模板经实参推导或显式模板实参形成实例。操作必须对被实例化类型有效，不能仅因写了 typename 就接受任意类型。
