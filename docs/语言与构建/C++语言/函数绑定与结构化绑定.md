# 函数绑定与结构化绑定

## std::bind 与 Lambda

std::bind 位于 `<functional>`，以占位符重排调用参数，以普通绑定参数保存其衰变后的副本。需要保持引用语义时可使用 std::ref；保存指针或引用时须保证被引用对象的生命周期。

```cpp
#include <functional>
struct Processor {
    int process(int first, int fixed, int last) const
    {
        return first + fixed + last;
    }
};
int main()
{
    Processor processor;
    using namespace std::placeholders;
    auto bound = std::bind(&Processor::process, &processor, _2, 42, _1);
    auto lambda = [&processor](int a, int b) {
        return processor.process(b, 42, a);
    };
    return bound(10, 20) == lambda(10, 20) ? 0 : 1;
}
```

Lambda 的值捕获和引用捕获有不同的所有权与生命周期语义。回调被异步保存时，捕获局部对象的引用尤其容易悬空；捕获 this 也不会自动延长对象寿命。

## C++17 结构化绑定

结构化绑定用于符合规则的数组、类成员或 tuple-like 对象。`auto [x, y]`、`auto& [x, y]`、`const auto& [x, y]` 分别有不同的复制和引用效果。

```cpp
#include <map>
#include <tuple>
#include <utility>
int main()
{
    auto [first, second] = std::pair<int, int>{1, 2};
    std::map<int, int> values{{1, 10}};
    for (auto& [key, value] : values) {
        value += key;
    }
    auto [iterator, inserted] = values.insert({2, 20});
    auto found = values.find(1);
    if (found != values.end()) {
        auto& [key, value] = *found;
        value += key;
    }
    return first + second + iterator->second + (inserted ? 1 : 0);
}
```

map.find 返回迭代器，不能直接对 find 结果绑定成 key/value，需要先确认不是 end 再解引用。绑定个数必须匹配，三元素 tuple 不能只写两个绑定名。名为 `_` 的变量仍是普通变量，不是标准规定的可无限重复占位符。
