## 异常处理

C++ 提供了完善的异常处理机制，用于处理程序运行时的错误。

### 1 基本语法

- 抛出异常：`throw 异常对象;`

- 捕获异常：

  ```C++
  try {
      // 可能抛出异常的代码
  } catch (异常类型1 e) {
      // 处理异常类型1
  } catch (异常类型2 e) {
      // 处理异常类型2
  } catch (...) {
      // 处理所有其他异常
  }
  ```

### 2 异常类型

- 可以抛出任何类型的对象，包括基本类型、自定义类型
- 标准异常类：`std::exception`及其派生类，如`std::runtime_error`、`std::logic_error`等

### 3 动态异常规范与 noexcept

- 动态异常规范 throw(Type...) 在 C++11 弃用、C++17 移除；旧 throw() 还具有版本相关兼容规则，新代码使用 noexcept。
- noexcept(true) 声明不允许异常传播出该函数；违反时调用 std::terminate，并不是阻止函数体执行 throw 的语法检查。

------

栈展开会销毁已经完成构造的自动对象，RAII 用析构释放资源；未完成构造对象的析构函数不会按完整对象调用，但已构造子对象会被清理。捕获标准异常通常使用 const std::exception&，避免切片。关闭异常支持的嵌入式工具链需要采用相应错误返回策略，不能直接使用依赖异常传播的示例。
