# 嵌入式项目清单

## 开始前

- [ ] 写清板卡、内核、工具链、根文件系统和设备节点。
- [ ] 画出数据流、线程模型和资源所有权。
- [ ] 记录协议、分辨率、帧率、时延和功耗目标。

## 开发中

- [ ] 每个硬件接口都有最小测试和错误码。
- [ ] 关键函数有英文 Doxygen 注释，公共接口集中在头文件。
- [ ] 设备树、驱动、应用的配置项可追溯。
- [ ] 日志包含模块、时间、错误码和关键参数，不打印敏感数据。

## 交付前

- [ ] native 测试和目标板回归均通过。
- [ ] 覆盖断电、拔插、超时、满队列和异常输入。
- [ ] 给出启动命令、依赖库、资源文件和性能基线。
- [ ] 更新技术文档与方案记录，保留可复现的调试证据。
